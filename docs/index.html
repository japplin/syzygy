Syzygy ties a branch’s dependency graph to the presenter that produces its state and the UI that renders it.

Read the guide

One graph per branch

Call alignGraph inside syzygy and return your presenter’s state. Compose keeps the graph across recompositions. Changing the key replaces the branch and its descendants.

In the Android sample, Settings creates a child graph for Rename. The graph supplies the presenter, and the presenter’s state selects the dialog renderer. During an exit transition, a projection keeps its graph open until Compose removes the outgoing UI.
